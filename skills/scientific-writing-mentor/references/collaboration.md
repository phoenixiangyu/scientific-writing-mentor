# Optional collaboration

Use the actual installed-skill catalog and read a chosen entrypoint. Names and invocation syntax vary by host. No collaborator is a mandatory dependency.

| Need | Candidate | Division of work |
|---|---|---|
| Existing academic prose | `nature-polishing` | Mentor sets reader/section diagnosis and comments policy; collaborator refines prose. |
| New section or reconstructed argument | `nature-writing` | Share the question, evidence, outline and venue; use relevant section guidance. |
| Empty self-defence or formulaic AI style | `humanizer`, `humanizer:humanizer`, `anti-defensive-writing` | Use after structure; preserve necessary limitations, negative findings, references and claim strength. |
| Literature or references | `nature-academic-search`, `nature-ref-verifier`, `citation-management` | Return verified metadata, source locators and unresolved support questions. |
| Review synthesis | `literature-review` | Own search/screening provenance; mentor can structure the manuscript. |
| Statistics | `nature-statistics` | Check reporting and experimental units; new analyses require a request and data. |
| Figures | `nature-figure` | Mentor provides the figure question and finding; collaborator owns plots and visual checks. |
| DOCX / PDF / LaTeX | Host document, PDF or LaTeX skills | Own file preservation, commenting, rendering and compilation with the host's required editor/workflow. |

## Handoff

Share relevant source, requested scale, venue/article type, confirmed claims/data, immutable details, output format and anchored issues. A prior model's revision is not new evidence.

Keep one manuscript owner. Give collaborators distinct tasks; do not allow concurrent overwrites. Use subagents only when separately permitted by host and user; this skill does not require them. Reuse established follow-up context and stop recursive mentor–polisher invocation loops.

Integrate once, then verify fidelity. Evidence and the user's comments contract override blanket word bans, automatic figures, fixed paragraph counts or instructions to suppress unfavorable findings. Journal-specific format comes from the actual target venue.

Without a collaborator, continue with the bundled guidance and existing host tools. Record unavailable verification precisely, outside the paper. Missing citation or rendering services need not block ordinary prose editing.
