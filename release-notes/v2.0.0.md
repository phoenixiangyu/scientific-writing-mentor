## 导师写作偏好成为默认规则

本版把导师反复强调的修改要求写入技能入口、分节指导、语言规则和协作交接。沿用 `$scientific-writing-mentor` 名称，无需更换调用方式；任务匹配时仍可自动选用。

- **聚焦、精炼、自然：**突出主题，删除套话和同义重复；同一要点一句能说清楚就不拆成两句，也不为压缩牺牲逻辑和信息。
- **结果开头有目的：**每节先交代科学问题、比较目的或承接背景，再进入数值结果，避免报图式开场。
- **结果段落有结论：**每段都有明确、证据支持的结论性表述；段尾给出简洁总结或局部 implication，已有收束则不再重复。
- **衔接与价值：**明确前后段的推理关系，先呈现已证实的贡献，再交代相关权衡与边界；保留影响结论的负结果和限制。
- **图文合讲：**围绕科学问题整合相关图或面板，不再默认一图一段。
- **Caption 简短且充分：**保留读图所需条件、符号、单位、误差线和统计信息，去掉重复讨论及冗长实验步骤。
- **保留既定结构：**普通润色默认不大改 Methods 以外的章节和论证次序；Methods 可优化组织，实际研究内容不变。新大纲、明确重构要求和当前用户范围优先。

这些是作者的写作偏好，不是所有期刊的强制格式，也不授权编造实验、机制、引用或显著性。与 nature-writing、nature-polishing 等技能协作时，会一并传递这些要求。

## 下载与更新

- Windows：下载 `scientific-writing-mentor-v2.0.0-setup.exe`，双击安装；旧版完整备份后更新。
- 其他支持 SKILL.md 的环境：下载 `scientific-writing-mentor-v2.0.0.zip`，按宿主要求安装完整技能目录。
- `SHA256SUMS.txt` 提供上述两个文件的校验值。教材留在仓库，不打入安装包。

技能入口版本为 2.0.0。Windows 安装器不要求管理员权限或 Python，当前未数字签名。
