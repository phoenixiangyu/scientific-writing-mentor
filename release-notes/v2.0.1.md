## 修正结构调整规则

根据作者纠正，撤回 v2.0.0 中“默认保留 Methods 以外的既定结构，Methods 可单独重组”的错误偏好。

- 所有章节采用相同的任务范围标准，不再按 Methods 与非 Methods 区分。
- 语言层润色或用户明确固定提纲时，保留组织结构。
- 实质修改、逻辑优化和明确要求重构时，按科学问题和证据关系调整句序、段序、段落合并及章节组织；重要改动在正文之外简要说明。
- 不把现有标题和顺序自动视为不可调整，也不扩大局部任务。
- 保留 v2.0 的其余导师要求：主题聚焦、精炼自然、结果开头有目的、每段有结论、衔接清楚、相关图合讲、caption 简短充分，以及事实与证据边界保护。

已同步修正技能入口、导师重点、协作交接、来源说明、人工验收场景和 README。ZIP 与 Windows EXE 均为 2.0.1，安装器更新前保留备份。当前 EXE 未数字签名；技能并非独立 AI 写作软件。

验证包括技能格式与引用路径、8 项批注契约测试，以及 Windows 安装器隔离安装、完整性检查和备份测试。此前 v2.0 的单场景写作检验不作为这次结构纠正的独立模型评测。
