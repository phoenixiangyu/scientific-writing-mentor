首个正式版本：把教材中的科技写作指导转化为可复用的 AI 写作 skill。

## 功能

- 支持论文大纲、章节起草、论证重构、中英文修改润色。
- 根据任务匹配自动选用，支持显式调用 `$scientific-writing-mentor`。
- 支持 ES&T、Nature 及具体子刊的写作适配；精确格式要求以当前官方指南为准。
- 按需结合已安装的 nature-writing、nature-polishing、文献检索、统计、文档和语言风格 skills；协作者均为可选项。
- 正文保持流畅，把论据缺失和核实问题放在锚定批注或附带清单中；不编造研究事实或改变证据强度。
- 附批注检查工具、示例和来源映射。

## 下载与安装

下载 `scientific-writing-mentor-v1.0.0.zip`，解压后将完整的 `scientific-writing-mentor` 文件夹放入个人 skills 目录（例如 `~/.codex/skills/`）。

也可以让 Codex 安装固定版本：

```text
请安装 https://github.com/phoenixiangyu/scientific-writing-mentor/tree/v1.0.0/skills/scientific-writing-mentor
```

`SHA256SUMS.txt` 提供安装包校验值。安装包包含 skill 和许可说明，不包含大型教材。

## 来源材料与许可

仓库的 [source-materials](https://github.com/phoenixiangyu/scientific-writing-mentor/tree/v1.0.0/source-materials) 提供用户所给教材的 503 页联系方式脱敏分卷及 24 页脱敏课件。原件部分扫描图像存在解码异常，已在材料说明中记录。

新编写的 skill、代码和说明采用 MIT；教材和课件保留原权利人的版权，不在 MIT 许可范围内。
