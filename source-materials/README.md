以下两份来源材料以联系方式脱敏副本提供，保留作者、书名、出版信息和教学内容；教材分卷保存，本机原文件没有修改。版权归原权利人，本仓库 MIT 许可不涵盖它们。

## 教材 PDF

共 503 页。为适应上传工具的单次传输限制，按连续页码拆分为多个 PDF，页码范围见文件名和 `page-manifest.json`；没有重新采样或降低图像质量。以下页码均指原 PDF 的页序。PDF 第 2 页去除联系/店铺二维码和对应标签；第 4 页去除联系地址、邮编、电话、网址、邮箱和售后电话。使用图像内容删除后重新保存并清理未使用对象，不是可撤除的白色覆盖标注；同时清空文档元数据、附件和外部链接。已重新打开并检查修改页，逐一检查所有分卷的页面可加载性。

对全部页面进行了 OCR 联系线索筛查并人工复核命中项。原文件部分 JPX 图像存在解码错误，主要集中在 PDF 第 337–369 页；也有少量空白页。此问题在原件中即存在，脱敏副本保留其页序和原有未修改页。无法解码的区域不能视为已完成内容或隐私核验；OCR 本身也不能证明所有图像中的信息都已被识别。
